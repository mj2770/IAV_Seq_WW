Input data for plotting. All raw sequencing data for this project have been deposited in the NCBI Sequence Read Archive (SRA) under BioProject ID PRJNA1336326.

- Note: Due to the size of the summarized dataset, the data have been separated by sequencing method. In the analyses presented in this paper, we use a single overall_summary.csv file (as shown in the Results analysis script), which is generated by combining all CSV files provided in this folder.
